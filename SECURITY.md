# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for this repository:

https://github.com/WasiRaza895/AgentForge-/security/advisories/new

Include the affected version, reproduction steps, potential impact, and any suggested mitigation. Remove real credentials and personal data from examples. You should receive an acknowledgement within 72 hours.

## Credential safety

AgentForge can perform write actions on external services. Use least-privilege tokens, test against non-production accounts first, review workflows before running them, and rotate any credential that may have been exposed.

Only the latest release is expected to receive security fixes while the project is in alpha.
